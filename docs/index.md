## Projetos

Durante minha graduação em Análise e Desenvolvimento de Sistemas tive a oportunidade de participar de alguns projetos.


###### SiloTech - SiloSignal
A SiloTech é uma empresa ficticia criada por mim e meus colegas de grupo no primeiro semestre de faculdade, este projeto simula o monitoramento de gases explosivos dentro de silos de soja, buscando monitorar e evitar grandes acidentes para nossos clientes, além de um site institucional, oferece dashboards que mostram esses dados em tempo real. Utilizamos o arduíno para simular a captura destes dados, o MySQL para o armazenamento deles e tecnologias como HTML, CSS, NodeJS e Javascript para o front-end e conexão com o banco.

> GitHub: [SiloSignal](https://github.com/GuilhermeAnSouza/SILO-SIGNAL-SPRINT2)

###### GamerCave
No primeiro semestre também tive a oportunidade de desenvolver um projeto individual onde reuni todo o aprendizado do semestre, o qual eu nomeei GamerCave, pois fiz pensando no meu principal hobby da minha adolescência que era jogar. O GamerCave simulava uma rede social, de maneira bem simples, o usuario podiam fazer publicações simples, fazer pequenas edições em seus perfis e ver recomendações de jogos de diferentes tipos, além disso havia uma dashboard onde era possivel visualizar os dados dos usuários da plataforma.

> GitHub: [GamerCave](https://github.com/ShirleyFerr/GAMERCAVE---Projeto-Individual)
