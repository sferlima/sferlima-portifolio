# Testes Unitários
Testes unitários são um tipo de teste automatizado que verifica se uma unidade específica de código (funções, métodos, classes) funciona corretamente. Assim, facilita a manutenção, garante a qualidade do código, podendo ser usado como uma documentação viva do projeto.

#### AAA

A estrutura de um teste é dividida em 3 partes conhecidas como AAA (Arrange, Action & Assert). 

1. Arrange (Preparação): Prepara o que vai ser testado, ou seja, objetos, mocks, valores de entrada, etc.

2. Action (Ação): Chama o metódo que você quer testar

3. Assert (Asserção): Verifica se o resultado é o que é esperado, por exemplo: o teste deve retornar status 200, se não retornar isso logo o teste falhou.
