# API REST

API (Application Programming Interface) é basicamente uma forma de sistemas diferentes se comunicarem, funcionando como uma ponte entre dois softwares.API REST (Representational State Transfer) é um tipo específico de API que segue algumas regras definidas. Esse tipo de API trabalha com requisições e respostas, geralmente usando o protocolo HTTP. 

Essas requisições usam métodos bem conhecidos como por exemplo:

- GET: para buscar informações

- POST: para criar algo novo

- PUT ou PATCH: para atualizar algo

- DELETE: para deletar algo

Uma API REST pode ser desenvolvida usando várias linguagens de programação, sendo as mais comuns JavaScript, Python, Java, C# e PHP. Essas linguagens oferecem frameworks que facilitam bastante a criação das APIs, automatizando tarefas como o roteamento de requisições e o tratamento de dados.

Essas APIs geralmente usam o formato JSON para trocar informações entre o cliente e o servidor, por ser leve, fácil de ler e amplamente aceito. Elas também costumam se conectar a bancos de dados como MySQL, SQL Server, MongoDB, entre outros, dependendo da necessidade do projeto.

Além da linguagem e do banco, outras ferramentas são muito usadas no desenvolvimento de APIs REST. O Postman, Insomnia e o ThunderClient são exemplos que ajudam a testar as rotas da API.

O Swagger é usado para documentar a API de forma visual e interativa, facilitando a vida de quem vai usar ou manter o sistema.
